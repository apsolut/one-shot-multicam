`face_detection_yunet_2023mar.onnx`: YuNet face detector (5 landmarks incl. mouth corners) from
[opencv/opencv_zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet), MIT license.
Used only by `multicam/lipcheck.py` (the "frozen while speaking" insert check). ~230 KB, CPU, OpenCV >= 4.8.
